# 画像ファイル配置場所

このフォルダにユーザー画像を配置してください。

## 手順

1. このフォルダ（`public/images/`）に画像ファイルを配置
   - 例: `user1.jpg`, `pro_a.jpg` など
2. `data/users.ts` を開いて、各ユーザーの `photo` フィールドにパスを記入
   - 例: `photo: '/images/user1.jpg'`
3. `photo` を空文字 `''` のままにすると、グレーアバター（イニシャル表示）になります

## 推奨仕様

- フォーマット: JPG / PNG / WebP
- サイズ: 正方形（500x500px〜1000x1000px 程度）
- ファイルサイズ: 1ファイルあたり 500KB 以下推奨

## 法的・倫理的な注意

- **顔写真を使用する場合は、必ず本人の同意・肖像権の許諾を得てから使用してください**
- フリー素材を使う場合は、利用規約を必ずご確認ください
  - [Pexels](https://www.pexels.com/) - 無料・商用利用可（要規約確認）
  - [Unsplash](https://unsplash.com/) - 無料・商用利用可（要規約確認）
- AI生成画像を使用する場合も、生成サービスの利用規約に従ってください
